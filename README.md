Este é um projeto desenvolvido como parte dos meus primeiros passos e estudos em HTML e CSS.
O objetivo principal foi praticar a estruturação de páginas web com HTML e a estilização de layouts com CSS, criando uma aplicação temática voltada para o universo do cinema.


🛠️ Tecnologias Utilizadas
HTML5: Estruturação das páginas e marcação de conteúdo (index.html, page.html).
CSS: Estilização visual, design e organização dos elementos (style.css).

📁 Estrutura de Arquivos
index.html: Página principal do projeto.
page.html: Página secundária.
style.css: Arquivo de estilos responsável pela aparência visual.
image1.jpeg, image3.jpeg, img2.jpeg: Imagens utilizadas no layout.
Projeto desenvolvido para fins de aprendizado e evolução no desenvolvimento web.
